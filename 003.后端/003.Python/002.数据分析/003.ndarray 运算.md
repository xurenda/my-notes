# 矢量化运算

- NumPy 中的数组不用编写循环即可执行批量运算，称之为矢量化运算
- 大小相等的数组之间的任何算术运算都会将运算应用到元素级

```python
arr1 = np.array([[1, 2, 3], [4, 5, 6]])
arr2 = np.array([[7, 8, 9], [10, 11, 12]])
print(arr1 + arr2)
print(arr1 - arr2)
print(arr1 * arr2)
print(arr1 / arr2)
```

数组与标量的算术运算会将标量值传播到各个元素

```python
arr1 = np.array([[1, 2, 3], [4, 5, 6]])
print(arr1 + 100)
print(arr1 - 100)
print(arr1 * 100)
print(arr1 / 100)
```

# 广播机制

数组在进行矢量化运算时，**要求数组的形状是相同的**。当不同形状的数组执行算术运算时，就会出现广播机制，该机制会对数组进行扩展，使数组形状相同（`shape` 属性值一样）

```python
arr1 = np.array([[0],[1],[2],[3]])  # (4, 1)
arr2 = np.array([1,2,3])            # (3,)

arr1+arr2
"""
array([[1, 2, 3],
       [2, 3, 4],
       [3, 4, 5],
       [4, 5, 6]])
"""
```

![[image-20190620005224076.png]]

广播主要发生在两种情况：

1. 一种是两个数组的维数不相等，但是它们的后缘维度的轴长相符
2. 另外一种是有一方的长度为 1

广播机制的具体规则：

1. 如果俩个数组的维度数不相同，那么小维度数组的形状会在左边补 1，使其维度数一致
2. 从最后一个维度开始比较，如果两个数组在该维度上的长度相同，或其中一个数组在该维度的长度为 1，那么它们在该维度上是兼容的，可以进行运算
3. 如果在任何一个维度上，两个数组的长度既不同又都不为 1，那么会引发异常

```python
# 规则 1
arr1 = np.array([1, 2, 3])        # 形状为 (3,)
arr2 = np.array([[4], [5], [6]])  # 形状为 (3, 1)
# 对 arr1 应用规则 1，在其形状最左边补 1，变为 (1, 3)=>[[1,2,3]]
# 此时 arr1 和 arr2 维度相同
result = arr1 + arr2

# 规则 2
arr3 = np.array([[1, 2, 3]])      # 形状为 (1, 3)
arr4 = np.array([[4], [5], [6]])  # 形状为 (3, 1)
# arr3 沿着第 0 个维度扩展，将原有的一行数据复制成 3 行，变为 (3, 3)=>[[1,2,3], [1,2,3], [1,2,3]]
# arr4 沿着第 1 个维度扩展, (3, 3)=>[[4,4,4], [5,5,5], [6,6,6]]
result = arr3 + arr4

# 规则 3
arr5 = np.array([1, 2, 3])  # 形状为 (3,)
arr6 = np.array([4, 5])     # 形状为 (2,)
try:
    result = arr5 + arr6
    print(result)
except ValueError as e:
    print(f"规则 3 示例错误信息：{e}")
```

矢量化运算和广播机制：

| |矢量化运算|广播机制|
|---|---|---|
|**目标**|避免显式循环，提升计算效率|解决不同形状数组的运算问题|
|**依赖关系**|广播机制是矢量化运算的补充|广播机制使矢量化运算更灵活|
|**形状要求**|通常要求数组形状相同|允许形状不同，但需满足广播规则|
|**底层实现**|基于优化过的 C/Fortran 代码|自动扩展数组，不实际复制数据|

关键联系：

- 广播机制扩展了矢量化运算的适用范围
	- 如果没有广播机制，矢量化运算只能用于形状完全相同的数组
	- 而广播机制让矢量化运算可以处理更多情况（如标量与数组、行向量与列向量等）
- 广播机制本身也是矢量化实现的
	- 广播的数组扩展是隐式的（不真正复制数据）
	- 底层仍然用优化过的代码计算，因此效率很高

# 矩阵乘法

通过 `*` 运算符或 `np.multiply()` 函数对两个数组相乘进行的是对位乘法而非矩阵乘法运算：

```python
arr1 = np.array([[1, 2, 3], [4, 5, 6]])
arr2 = np.array([[6, 5, 4], [3, 2, 1]])
print(arr1 * arr2)
print(np.multiply(arr1, arr2))
"""
[[ 6 10 12]
 [12 10  6]]
"""
```

使用 `np.dot()`、`ndarray.dot()`、`@` 可以进行矩阵乘法运算

矩阵乘法：`A @ B`

- 要求 A 矩阵的列数等于 B 矩阵的行数
- 结果矩阵形状为：A 矩阵的行数 x B 的列数
- 即：`(a, b) @ (b, c) = (a, c)`

具体规则是：结果矩阵中第 `i` 行第 `j` 列的元素等于 A 矩阵的第 `i` 行与 B 矩阵的第 `j` 列对应元素乘积之和

```python
arr1 = np.array([[1, 2, 3], [4, 5, 6]])    # (2, 3)
arr2 = np.array([[6, 5], [4, 3], [2, 1]])  # (3, 2)

print(arr1.shape, arr2.shape)
# (2, 3) (3, 2)

print(np.dot(arr1, arr2))
print(arr1.dot(arr2))
print(arr1 @ arr2)
"""
[[20 14]
 [56 41]]
"""
```

# 逻辑运算

```python
# 生成 10 名同学，5 门功课的数据
score = np.random.randint(40, 100, (10, 5))

# 取出最后 4 名同学的成绩，用于逻辑判断
test_score = score[-4:, :]

# 逻辑判断：如果成绩大于 60 就标记为 True 否则为 False
test_score > 60
"""
array([[False, False, False,  True,  True],
       [False,  True,  True,  True, False],
       [False, False,  True,  True,  True],
       [ True, False,  True,  True,  True]])
"""

# 布尔索引：将满足条件的索引设置为指定的值
test_score[test_score > 60] = 1
test_score
"""
array([[44, 53, 47,  1,  1],
       [49,  1,  1,  1, 43],
       [46, 46,  1,  1,  1],
       [ 1, 50,  1,  1,  1]])
"""
```

# 判断函数

- `np.all()`：检查数组中的**所有**元素是否都满足条件

```python
# 判断前两名同学的成绩 [0:2, :] 是否全及格
np.all(score[0:2, :] > 60)
# False
```

- `np.any()`：检查数组中是否至少有一个（**任一**）元素满足条件

```python
# 判断前两名同学的成绩 [0:2, :] 是否有大于 90 分的
np.any(score[0:2, :] > 80)
# True
```

- `np.where()`：类似 if...else 或三元运算符

```python
# 前四名学生，前四门课程中，成绩中大于 60 的置为 1，否则为 0
temp = score[:4, :4]
np.where(temp > 60, 1, 0)
```

* `np.logical_and`、`np.logical_or`、`np.logical_not`：复合逻辑

```python
# 前四名学生，前四门课程中，成绩中大于 60 且小于 90 的置为 1，否则为 0
np.where(np.logical_and(temp > 60, temp < 90), 1, 0)

# 前四名学生，前四门课程中，成绩中大于 90 或小于 60 的置为 1，否则为 0
np.where(np.logical_or(temp > 90, temp < 60), 1, 0)
```

# 统计运算

常用的统计指标如下：

- `np.sum(x, axis)`：求和
- `np.min(a, axis)`：最小值
- `np.max(a, axis)`：最大值
- `np.median(a, axis)`：中位数
- `np.mean(a, axis, dtype)`：算术平均值
- `np.std(a, axis, dtype)`：标准差
	- 标准方差是衡量数据点离平均值的平均偏差程度。值越小，数据越集中；值越大，数据越分散
- `np.var(a, axis, dtype)`：方差
	- 方差是衡量数据点离平均值的平方偏差程度。方差的值总是非负的，方差越大，数据越分散

```python
temp = score[:4, :]
"""
array([[52, 72, 78, 88, 60],
       [56, 63, 56, 44, 55],
       [72, 98, 85, 90, 67],
       [55, 95, 51, 71, 71]])
"""

print("前四名学生，各科成绩的最大分：{}".format(np.max(temp, axis=0)))
# [72 98 85 90 71]
print("前四名学生，各科成绩的最小分：{}".format(np.min(temp, axis=0)))
# [52 63 51 44 55]
print("前四名学生，各科成绩波动情况（标准差）：{}".format(np.std(temp, axis=0)))
# [ 7.79021823 14.88287607 14.32654878 18.43061312  6.17960355]
print("前四名学生，各科成绩的平均分：{}".format(np.mean(temp, axis=0)))
# [58.75 82.   67.5  73.25 63.25]
```

在 NumPy 中，轴是对数组维度的一种抽象描述。对于多维数组，每个维度都对应一个轴，轴的编号从 0 开始

对于二维数组，它有两个轴：

- `axis=0`：代表垂直方向，也就是行的方向，按列操作
- `axis=1`：代表水平方向，也就是列的方向，按行操作

可以把二维数组想象成一个表格，轴 0 就像是表格中从上到下的行索引方向，轴 1 是从左到右的列索引方向

本例中：

- `axis=0`：语文这科谁考的最高？
- `axis=1`：第一个学生哪科考的最高？

获取对应的索引，而不是值：

- `np.argmax(temp, axis)`
- `np.argmin(temp, axis)`
- ...

```python
print("前四名学生，各科成绩最高分对应的学生下标：{}".format(np.argmax(temp, axis=0)))
# [2 2 2 2 3]
```

# 其他常用函数

## 基本数学

- `np.sqrt(x)`：平方根
- `np.exp(x)`：指数（`e^x`）
- `np.log(x)`：自然对数（`ln(x)`）
- `np.sin(x)`：正弦值
- `np.abs(x)`：绝对值
- `np.power(a, b)`：a 的 b 次幂
- `np.round(x, n)`：四舍五入（保留 n 位小数）
- `np.ceil(x)`：向上取整（不小于原数的最小整数）
- `np.floor(x)`：向下取整（不大于原数的最大整数）

## 统计

- `np.sum(x)`：总和
- `np.size(x)`：计数，数组中元素的总个数（包含缺失值）
- `np.count_nonzero(x)`：非零计数
- `np.mean(x)`：平均
- `np.average(x, weights=)`：加权平均
- `scipy.stats.mode(x)`：众数（需 SciPy 支持）
- `np.ptp(x)`：极差，最大值与最小值的差
- `np.quantile(x, q)`：分位数，q 范围 `[0, 1]`
- `np.percentile(x, q)`：百分位数，q 范围 `[0, 100]`
	- `quantile(0.25) == percentile(25)`
- `np.cov(x)`：协方差矩阵，变量间协方差的矩阵表示（每对变量的协方差）
- `np.corrcoef(x)`：标准化的协方差矩阵，范围 `[-1, 1]`
- `np.histogram(x)`：直方图统计，将数据划分到等宽区间并计数
- `np.cumsum(x)`：累积和
    - `np.cumsum([1, 2, 3]) -> [1, 3, 6]`
- `np.cumprod(x)`：累积积
    - `np.cumprod([1, 2, 3]) -> [1, 2, 6]`
- `np.unique(x)`：唯一值，返回排序后的唯一值数组（可附加计数）
- `np.trace(x)`：迹（矩阵），矩阵主对角线元素的和
- `np.linalg.norm(x)`：范数，向量的模（如 L2 范数为欧几里得距离）

关键说明：

1. **轴方向控制**：多数函数支持 `axis` 参数
2. **缺失值处理**：
	- 统计函数默认忽略 NaN
	- 需用 `nanxxx` 相关函数（如 `np.nansum()`）处理含 NaN 的数据
3. **精度控制**：可通过 `dtype` 参数指定计算精度
4. **高维扩展**：所有统计量均支持高维数组，通过 `axis` 元组指定多轴（如 `axis=(1,2)`）

## 比较

- `np.greater(a, b)`：元素级比较 a > b
- `np.less(a, b)`：元素级比较 a < b
- `np.equal(a, b)`：元素级比较 a == b
- `np.logical_and(a, b)`：逻辑与（逐元素）

注意事项：

1. **默认行为**：`np.any()` 和 `np.all()` 默认对整个数组操作，但可通过 `axis` 参数按轴计算
2. **布尔数组处理**：非布尔数组会被隐式转换为布尔值（0 为 False，非零为 True）
3. **空数组处理**：
	- `np.any([])` 返回 False（无元素满足条件）
	- `np.all([])` 返回 True（所有元素均满足条件，属于逻辑真空情况）

## 排序

- `np.sort(x)`：返回排序后的副本
- `x.sort()`：原地排序（修改原数组）
- `np.argsort(x)`：返回排序后的索引
- `np.lexsort(keys)`：多键排序（按最后一列优先）

`axis`：指定排序的轴。默认值为 `-1`，表示沿着最后一个轴进行排序

## 去重

- `np.unique(x)`：返回唯一值并排序
- `np.in1d(a, b)`：检查 a 的元素是否在 b 中存在

## 其他

- `np.concatenate((a, b))`：拼接数组
- `np.split(x, indices)`：分割数组
- `np.isnan(x)`：检测 NaN

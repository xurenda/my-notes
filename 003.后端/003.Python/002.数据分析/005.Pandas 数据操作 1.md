# 索引

## 直接使用行列索引

直接使用行列索引名字的方式（**先列后行**）

```python
# 获取 2018-02-27 这天的 close 数据
data['open']['2018-02-27']
# 23.53

# 不支持的操作
data['2018-02-27']['open'] # 错误
data[:1, :2] # 错误
```

## 结合 loc 或者 iloc 使用索引

- `loc`：只能指定行列索引的名字
- `iloc`：通过索引的下标去获取

```python
# 获取从 2018-02-27 到 2018-02-22，open 的数据
data.loc['2018-02-27':'2018-02-22', 'open']
"""
2018-02-27    23.53
2018-02-26    22.80
2018-02-23    22.88
Name: open, dtype: float64
"""

# 获取前 3 天数据，前 5 列的结果
data.iloc[:3, :5]
"""
            open    high    close    low
2018-02-27    23.53    25.88    24.16    23.53
2018-02-26    22.80    23.78    23.53    22.80
2018-02-23    22.88    23.37    22.82    22.71、
"""
```

# 排序

排序有两种形式，一种对于索引进行排序，一种对于内容进行排序

## DataFrame 排序

- `df.sort_values(by=, ascending=True)`：单个键或者多个键进行排序
	- `by`：指定排序参考的键
	- `ascending`：默认升序。True：升序；False：降序

```python
# 按照开盘价升序排序
data.sort_values(by="open").head()
```

![[Pasted image 20251123203424.png]]

```python
# 按照多个键进行排序
data.sort_values(by=['open', 'high'])
```

- `df.sort_index(ascending=True)`：按索引进行排序

```python
# 这个股票的日期索引原来是从大到小，现在重新排序，从小到大
data.sort_index()
```

![[Pasted image 20251123203839.png]]

## Series 排序

- `s.sort_values(ascending=True)`：按值进行排序
	- series 排序时，只有一列，不需要 `by` 参数

```python
data['p_change'].sort_values(ascending=True).head()
"""
2015-09-01   -10.03
2015-09-14   -10.02
2016-01-11   -10.02
2015-07-15   -10.02
2015-08-26   -10.01
Name: p_change, dtype: float64
"""
```

- `s.sort_index(ascending=True)`：按索引进行排序
	- 与 DataFrame 一致

```python
# 对索引进行排序
data['p_change'].sort_index().head()
"""
2015-03-02    2.62
2015-03-03    1.44
2015-03-04    1.57
2015-03-05    2.02
2015-03-06    8.51
Name: p_change, dtype: float64
"""
```

## rank 函数

- `rank(axis=0, method='average', numeric_only=False, na_option='keep', ascending=True, pct=False)`
	- `DataFrame.rank()` 或 `Series.rank()`
	- `axis`：沿着哪个轴计算排名
	- `method`：排名评分的计算方式
		- `'average'`：默认值，排名评分不连续；数值相同的评分一致，都为平均值
		- `'min'`：排名评分不连续；数值相同的评分一致，都为最小值
		-  `'max'`：排名评分不连续；数值相同的评分一致，都为最大值
		- `'dense'`：排名评分是连续的；数值相同的评分一致
	- `numeric_only`：是否仅仅计算数字型的 `columns`
	- `na_option` ：NaN 值是否参与排序及如何排序
		- `'keep'`：NaN 值保留原有位置
		- `'top'`：NaN 值全部放在前边
		- `'bottom'`：NaN 值全部放在最后
	- `ascending`：是否升序
	- `pct`：是否以排名的百分比显示排名（所有排名与最大排名的百分比）
	- 返回值：以 Series 或者 DataFrame 的类型返回数据的排名（哪个类型调用返回哪个类型）

```python
df7 = pd.DataFrame({
    '姓名':['小明', '小美', '小强', '小兰'],
    '成绩':[100, 90, 90, 80]
})

df7.rank()  # 等价于 df7.rank(method='average', ascending=True)
df7
"""
   姓名   成绩
0  小明  100
1  小美   90
2  小强   90
3  小兰   80
"""

df7['成绩排名'] = df7.成绩.rank(method='min', ascending=False)
df7
"""
   姓名   成绩  成绩排名
0  小明  100   1.0
1  小美   90   2.0
2  小强   90   2.0
3  小兰   80   4.0
"""

df7['成绩排名'] = df7.成绩.rank(method='max', ascending=False)
df7
"""
   姓名   成绩  成绩排名
0  小明  100   1.0
1  小美   90   3.0
2  小强   90   3.0
3  小兰   80   4.0
"""

df7['成绩排名'] = df7.成绩.rank(method='dense', ascending=False)
df7
"""
   姓名   成绩  成绩排名
0  小明  100   1.0
1  小美   90   2.0
2  小强   90   2.0
3  小兰   80   3.0
"""
```

# 逻辑运算

## 逻辑运算符号

```python
data["open"] > 23
"""
2018-02-27     True
2018-02-26    False
2018-02-23    False
2018-02-22    False
2018-02-14    False
"""

# 逻辑判断的结果可以作为筛选的依据
data[data["open"] > 23].head()

# 多个逻辑判断
data[(data["open"] > 23) & (data["open"] < 24)].head()
```

## 逻辑运算函数

- `query(expr)`
	- `expr`：查询字符串

```python
data.query("open<24 & open>23").head()
```

- `isin(values)`

```python
# 可以指定值进行一个判断，从而进行筛选操作
data[data["open"].isin([23.53, 23.85])]
```

## 统计函数

以下这些函数可以对 Series 和 DataFrame 操作

| 函数       | 作用         |
| -------- | ---------- |
| `count`  | 非 N/A 元素数量 |
| `sum`    | 和          |
| `mean`   | 平均值        |
| `median` | 中位数        |
| `min`    | 最小值        |
| `max`    | 最大值        |
| `mode`   | 众数         |
| `abs`    | 绝对值        |
| `prod`   | 乘积         |
| `std`    | 标准差        |
| `var`    | 方差         |
| `idxmin` | 最小值的索引     |
| `idxmax` | 最大值的索引     |

单个函数进行统计时，坐标轴默认按列（columns, axis=0），如果要对行（index）则需要指定（axis=1）

```python
# 使用统计函数：0 代表列求结果， 1 代表行求统计结果
data.max(0)
"""
open                   34.99
high                   36.35
close                  35.21
low                    34.01
volume             501915.41
price_change            3.03
p_change               10.03
turnover               12.56
my_price_change         3.41
dtype: float64
"""
```

```python
# 最小值的索引
data.idxmin(axis=0)

```

## 累计统计函数

| 函数        | 作用                   |
| --------- | -------------------- |
| `cumsum`  | 计算前 1/2/3/…/n 个数的和   |
| `cummax`  | 计算前 1/2/3/…/n 个数的最大值 |
| `cummin`  | 计算前 1/2/3/…/n 个数的最小值 |
| `cumprod` | 计算前 1/2/3/…/n 个数的积   |

```python
# 按照时间的从前往后进行排序
data = data.sort_index()
# 对 p_change 进行累计求和
stock_rise = data['p_change']
stock_rise.cumsum()
```

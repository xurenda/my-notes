Pandas 是 Python 的一个第三方包，也是商业和工程领域最流行的**结构化数据**工具集，用于数据清洗、处理以及分析

Pandas 在数据处理上具有独特的优势：

- 底层是基于 Numpy 构建的，所以运行速度特别的快
- 有专门的处理缺失数据的 API
- 强大而灵活的分组、聚合、转换功能

## DataFrame

DataFrame 是一个类似于二维数组或表格（类比 excel）的对象，既有行索引，又有列索引

- `index`：行索引，表明不同行，横向索引，0 轴，axis=0
- `columns`：列索引，表名不同列，纵向索引，1 轴，axis=1

![[image-20240831110104120.png]]

### 创建 DataFrame 对象

```python
# 读取文件数据创建
pd.read_csv('csv格式数据文件路径')

# 使用字典加列表创建，默认自增索引
df1_data = {
    '日期': ['2021-08-21', '2021-08-22', '2021-08-23'],
    '温度': [25, 26, 50],
    '湿度': [81, 50, 56] 
}
pd.DataFrame(data=df1_data)
"""
        日期    温度    湿度
0    2021-08-21    25    81
1    2021-08-22    26    50
2    2021-08-23    50    56
"""

# 自定义索引
df2_data = [
    ('2021-08-21', 25, 81),
    ('2021-08-22', 26, 50),
    ('2021-08-23', 27, 56)
]
pd.DataFrame(
    data=df2_data, 
    columns=['日期', '温度', '湿度'],
    index = ['row_1','row_2','row_3'] # 手动指定索引
)
"""
            日期    温度    湿度
row_1    2021-08-21    25    81
row_2    2021-08-22    26    50
row_3    2021-08-23    27    56
"""

# 使用 numpy 创建

# 生成 10 名同学，5 门功课的数据
score = np.random.randint(40, 100, (10, 5))
score_df = pd.DataFrame(score)
"""
```

- 修改行列索引值

```python

stu = ["学生_" + str(i) for i in range(score_df.shape[0])]
```

- `set_index(keys, drop=True)`：以某列值设置为新的索引
	- `keys`：列索引名称或列索引名称的列表
	- `drop`：是否当做新的索引，删除原来的列
	- 返回新的 DataFrame 对象，不影响原来的 DataFrame 对象

```python
df = pd.DataFrame({'month': [1, 4, 7, 10],
                    'year': [2012, 2014, 2013, 2014],
                    'sale':[55, 40, 84, 31]})
"""
   month  sale  year
0  1      55    2012
1  4      40    2014
2  7      84    2013
3  10     31    2014
"""

# 以月份设置新的索引
df.set_index('month')
"""
       sale  year
month
1      55    2012
4      40    2014
7      84    2013
10     31    2014
"""

# 设置多个索引
df = df.set_index(['year', 'month'])
"""
            sale
year  month
2012  1     55
2014  4     40
2013  7     84
2014  10    31
"""
```

## Series 对象

Series 是 DataFrame 的列对象，Series 本身也具有索引

Series 是一种类似于一维数组的对象，由下面两个部分组成：

![[image-20240831105304751.png]]

- `values`：一组数据（`numpy.ndarray` 类型）
- `index`：相关数据的索引标签
	- 如果没有为数据指定索引，会自动创建一个 0 到 N-1（N 为数据的长度）的整数型索引

### 创建 Series 对象

```python
# 使用 list 列表创建，默认自增索引
pd.Series([1, 2, 3])
"""
0    1
1    2
2    3
dtype: int64
"""

# 自定义索引
pd.Series([1, 2, 3], index=['A', 'B', 'C'])
"""
A    1
B    2
C    3
dtype: int64
"""

# 使用元组创建
tst = (1, 2, 3, 4, 5, 6)
pd.Series(tst)

# 使用字典创建
dst = {'A':1, 'B':2, 'C':3, 'D':4, 'E':5, 'F':6}
pd.Series(dst)

# 使用 numpy 创建
pd.Series(np.arange(10))
```

### Series 对象属性

```python
s4 = pd.Series([i for i in range(6)], index=[i for i in 'ABCDEF'])
s4
"""
A    0
B    1
C    2
D    3
E    4
F    5
dtype: int64
"""

s4.index
# Index(['A', 'B', 'C', 'D', 'E', 'F'], dtype='object')

s4.values
# array([0, 1, 2, 3, 4, 5], dtype=int64)

# 也可以通过索引来获取数据
s4['A'] # 0
```

# 数据类型

DataFrame 或 Series 对象中具体每一个值的数据类型有很多，如下表所示：

| Pandas 数据类型 | 说明   | 对应的 Python 类型                 |
| ----------- | ---- | ----------------------------- |
| `Object`    | 字符串  | `string`                      |
| `int`       | 整数   | `int`                         |
| `float`     | 浮点数  | `float`                       |
| `datetime`  | 日期时间 | `datetime` 包中的 `datetime` 类型  |
| `timedelta` | 时间差  | `datetime` 包中的 `timedelta` 类型 |
| `category`  | 分类   | 无原生类型，可以自定义                   |
| `bool`      | 布尔   | `bool`                        |
| `nan`       | 空值   | `None`                        |

可以通过下列 API 查看：

```python
s = pd.Series([i for i in range(6)], index=[i for i in 'ABCDEF'])
s.dtype
# dtype('int64')

df = pd.DataFrame({'month': [1, 4, 7, 10],
                    'year': [2012, 2014, 2013, 2014],
                    'sale':[55, 40, 84, 31]})
df.dtypes
"""
month    int64
year     int64

dtype: object
"""
```

## `datetime`

```python
dates = pd.to_datetime(['2024-09-01', '2024-09-02', '2024-09-03'])
dates
# DatetimeIndex(['2024-09-01', '2024-09-02', '2024-09-03'], dtype='datetime64[ns]', freq=None)
```

## `timedelta`

```python
# 计算两个日期之间的差值
start_date = pd.to_datetime('2024-09-01')
end_date = pd.to_datetime('2024-09-05')
delta = end_date - start_date
delta
# Timedelta('4 days 00:00:00')
```

## category

用于表示分类数据，通常用于有限集合中的数据类型，例如性别、颜色、产品类型等

这种类型的优点在于占用更少的内存，并且对分类数据的操作更快

```python
categories = pd.Series(['apple', 'banana', 'apple', 'orange'], dtype='category')
"""
categories
0     apple
1    banana
2     apple
3    orange
dtype: category
Categories (3, object): ['apple', 'banana', 'orange']
"""
```

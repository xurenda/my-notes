# 文件读取与存储


数据大部分存在于文件当中，Pandas 支持了复杂的 IO 操作，且支持的文件格式众多，如 CSV、SQL、XLS、JSON、HDF5 等

![[image-20240831125310359.png]]

## CSV

- `pandas.read_csv(filepath_or_buffer, sep =',', usecols)`
	- `filepath_or_buffer`：文件路径或 buffer
	- `sep`：分隔符
	- `usecols`：指定读取的列名，列表形式

```python
data = pd.read_csv("./data/stock_day.csv", usecols=['open', 'close'])
"""
            open    close
2018-02-27    23.53    24.16
2018-02-26    22.80    23.53
2018-02-23    22.88    22.82
2018-02-22    22.25    22.28
2018-02-14    21.49    21.92
"""
```

- `DataFrame.to_csv(path_or_buf=None, sep=', ’, columns=None, header=True, index=True, mode='w', encoding=None)`
	- `columns`：需要储存的列索引
	- `header`：boolean 或字符串列表
	- `index`：是否写进行索引，是否写进列索引值
	- `mode`：`'w'`：覆写；`'a'`：追加

```python
# 选取 10 行数据保存
data[:10].to_csv("./data/test.csv", columns=['open'])

# 读取
pd.read_csv("./data/test.csv")
"""
     Unnamed: 0    open
0    2018-02-27    23.53
1    2018-02-26    22.80
2    2018-02-23    22.88
3    2018-02-22    22.25
4    2018-02-14    21.49
5    2018-02-13    21.40
6    2018-02-12    20.70
7    2018-02-09    21.20
8    2018-02-08    21.79
9    2018-02-07    22.69
"""
```

## MySQL

以 MySQL 数据库为例，需要先安装与数据库交互所需要的 python 包

```shell
pip install pymysql==1.0.2
# 如果后面的代码运行提示找不到 sqlalchemy的包：
pip install sqlalchemy==2.0.0
```

准备要写入数据库的数据：

```python
import pandas as pd
df = pd.read_csv('./data/csv示例文件.csv', sep=',', index_col=[0])
df
```

![[image-20220123165416808.png]]

创建数据库操作引擎对象并指定数据库：

```python
# 需要安装 pymysql，部分版本需要额外安装 sqlalchemy
from sqlalchemy import create_engine

# 创建数据库引擎，传入 uri 规则的字符串
engine = create_engine('mysql+pymysql://root:123456@127.0.0.1:3306/test?charset=utf8')
# mysql：数据库类型
# pymysql：python 操作数据库的包
# root:123456：连接数据库的账号和密码
# 127.0.0.1:3306/test：数据库的 IP 和端口，以及库名
# charset=utf8：规定编码格式
```

将数据写入 MySQL 数据库：

```python
# 将 df 数据写入数据库
df.to_sql('test_pdtosql', engine, index=False, if_exists='append')
# 第一个参数：数据表的名称
# 第二个参数：数据库交互引擎
# index=False：不添加自增主键
# if_exists='append'：如果表存在就添加，表不存在就创建表并写入
```

从数据库中加载数据：

```python
from sqlalchemy import create_engine

engine = create_engine('mysql+pymysql://root:root@127.0.0.1:3306/test?charset=utf8')

# 读取整张表, 返回 DataFrame
pd.read_sql('test_pdtosql', engine)

# 使用 SQL 语句获取数据，返回 DataFrame
pd.read_sql('select name, AKA from test_pdtosql', engine)
```

## JSON

- `pandas.read_json(path_or_buf=None, orient=None, typ='frame', lines=False)`
	- `orient`：string，表示预期的 JSON 字符串格式
		- `'split'`：dict like `{index -> [index], columns -> [columns], data -> [values]}`
			- 将索引总结到索引，列名到列名，数据到数据。将三部分都分开了
		- `'records'`：list like `[{column -> value}, ... , {column -> value}]`
		- `'index'`：dict like `{index -> {column -> value}}`
		- `'columns'`：**默认值**，dict like `{column -> {index -> value}}`
		- `'values'`：只有 values 数组
	- `lines`：按照每行读取 JOSN 对象，即文件中每一行是一个 JOSN 字符串
	- `typ`：指定转换成的对象类型，`series` 或 `dataframe`
- `DataFrame.to_json(path_or_buf=None, orient=None, lines=False)`

# 数据的增删改查

```python
import pandas as pd

df = pd.read_csv('。/data/1960-2019全球GDP数据.csv', encoding='gbk')  
df2 = df.head()
```

## 增加列

### 直接赋值

```python
df3 = df2.copy()

# 一列数据都是固定值
df3['new col 1'] = 33

# 新增列数据数量必须和行数相等
df3['new col 2'] = [1, 2, 3, 4, 5]
df3['new col 3'] = df3.year * 2

# 分别查看
df3
df2
```

![[image-20220123170950953.png]]

### `df.assign`

```python
# 新列名是单个数据或一组数据，一组数据的数量必须和 df 的行数相同
df2.assign(new0=66)
# df2.assign(new1=[1, 2, 3, 4]) # 报错
df2.assign(new1=[1, 2, 3, 4, 5])

# 新列名是 Series 对象，该 s 对象的索引和 df 索引一致
s = pd.Series([1, 2, 3, 4, 5]) 
df2.assign(new2=s)

# 新列名是 Series 对象
df2.assign(new3=df2.year+df2.GDP)

# 新列名是自定义函数名
# 该自定义函数必须接收 df 作为参数
# 该自定义函数可以返回：
# - 单个数据 
# - 一组数据（和 df 的行数相同）
# - 和 df 索引相同的 Series 对象
def foo(df):
    # 可以返回一个变量
    # return 'hahah'
    # 可以返回一组变量
    ret = df.index.values
    return ret 
df2.assign(new4=foo)

# df.assign 函数可以同时添加多列
def foo(df):
    return 22
def bar(df):
    return df.year + 1
df2.assign(
    new0='hahaha',
    new1=[1, 2, 3, 4, 5],
    new2=pd.Series([1, 2, 3, 4, 5]),
    new3=df.year*2,
    new4=foo,
    new5=bar
)
```

## 删除与去重

- `df.drop(labels=None, *, axis=0)`
	- 返回删除后的 df 或 seires，原 df 或 seires 没有被修改

```python
df3.drop([0])                   # 默认删除行
df3.drop([0, 2, 4])             # 可以删除多行
df3.GDP.drop([0, 2])            # 对 series 对象按索引删除
df3.drop(['new col 3'], axis=1) # 删除列数据
```

- `df.drop_duplicates()`：去重

```python
# 添加一部分重复的数据
df4 = df2.append(df2).reset_index(drop=True)
# 实施去重操作
df4.drop_duplicates()
```

- series 去重

```python
方式一:
df4.country.drop_duplicates()

方式二:
df4.country.unique()
```

## 修改

* `df.assign` 替换列

```python
df5 = df.head()
df5 = df5.assign(GDP=66)
df # 此时原始的 df 不会发生改变
```

- 直接对原始的 df 进行赋值修改处理（不建议）

```python
df5 = df.head()
df5['GDP'] = [5, 4, 3, 2, 1]
df # 此时原始的 df 会发生改变
```

- `replace(to_replace=None, value=<no_default>, *, inplace=False)`：替换数据
	- `to_replace`：替换前的值
	- `value`：替换后的值
	- `inplace`：原地修改
	- 备注：是按照单元格元素值进行完全匹配

```python
df6 = df.head()
# series 对象替换数据，返回的还是 series 对象，不会对原来的 df 造成修改
df6.year.replace(1960, 19600)
# 如果加上 inplace=True 参数，则会修改原始 df
df6.country.replace('日本', '扶桑', inplace=True)

# df 也可以直接调用 replace 函数，用法和 s.replace 用法一致，只是返回的是 df 对象
df6.replace(1960, 19600)
```

## 查询

### 从前或后取多行数据

- `head(n=5)`
- `tail(n=5)`

### 获取一列或多列数据

- 获取一列数据

```python
df2['country']
df2.country
# 如果列名字符串中间有空格的，只能使用 df['country'] 这种形式
```

- 获取多列数据：`df[[col_name1,col_name2,...]]`

```python
df2[['country', 'GDP']] # 返回新的 df
```

### 索引下标切片取行

- `df[start:stop:step]`

```python
df4 = df.head(10)
df4[0:3]   # 取前 3 行
df4[:5:2]  # 取前 5 行，步长为 2
df4[1::3]  # 取第 2 行到最后所有行，步长为 3
```

### 查询函数获取子集

- `df.query(query)`
	- query：string，判断表达式
	- 与 `df[布尔值向量]` 效果相同

```python
df3.query('country=="帕劳"')
df3[df3['country']=='帕劳']

df.query('country=="中国" or country=="日本" or country=="美国"').query('year in ["2015", "2016", "2017", "2018", "2019"]')
df.query('(country=="中国" or country=="日本" or country=="美国") and year in ["2015", "2016", "2017", "2018", "2019"]')
```

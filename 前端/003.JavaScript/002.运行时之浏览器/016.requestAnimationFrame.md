# rAF 是什么

**`window.requestAnimationFrame()`**  告诉浏览器 —— 希望执行一个动画，并且要求浏览器在下次重绘之前调用指定的回调函数更新动画。该方法需要传入一个回调函数作为参数，该回调函数会在浏览器下一次重绘之前执行

rAF 是浏览器提供的和渲染帧率保持同步的一个 API，注意是渲染帧率不是屏幕刷新率

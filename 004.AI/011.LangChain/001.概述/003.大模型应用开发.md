# 4 种场景

## 场景 1：纯 Prompt

- Prompt 是操作大模型的唯一接口
- 当人看：你说一句，ta 回一句，你再说一句，ta 再回一句...

![[Pasted image 20251113195228.png|240]]

## 场景 2：Agent + Function Calling

- Agent：AI 主动提要求
- Function Calling：需要对接外部系统时，AI 要求执行某个函数
- 当人看：你问 ta「我明天去杭州出差，要带伞吗？」，ta 让你先看天气预报，你看了告诉 ta，ta 再告诉你要不要带伞

![[Pasted image 20251113195442.png|500]]

## 场景 3：RAG

- RAG：需要补充领域知识时使用
- Embeddings：把文字转换为更易于相似度计算的编码。这种编码叫向量
- 向量数据库：把向量存起来，方便查找
- 向量搜索：根据输入向量，找到最相似的向量
- 举例：考试答题时，到书上找相关内容，再结合题目组成答案
- 这个在智能客服上用的最广泛

![[Pasted image 20251113195725.png|500]]

## 场景 4：Fine-tuning

- 举例：努力学习考试内容，长期记住，活学活用
- 特点：成本最高；在前面的方式解决不了问题的情况下，再使用

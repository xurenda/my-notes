# 学习的参与度

1. 最简单的，比如看一本书，效果是最差的
2. 稍微好一点的，听别人讲，印象会深刻一些
3. 再往上，是即看又听，眼睛和耳朵一起参与，大脑会更加印象深刻
4. 下一个层次，是自己动手来做一遍
5. 再往上，你可以讲一遍，不仅会用，还已经理解，能够给别人讲

# 本地安装

## 课程代码

- 使用 [anaconda / miniconda](https://www.anaconda.com/download) 环境（[对比](https://docs.anaconda.net.cn/distro-or-miniconda/)）

```shell
conda env remove -n d2l-zh
conda create -n d2l-zh python=3.9 pip
conda activate d2l-zh
```

- 安装需要的包

```shell
pip install jupyter d2l
```

- 下载代码并执行

```shell
wget https://zh-v2.d2l.ai/d2l-zh.zip
unzip d2l-zh.zip
jupyter notebook
```

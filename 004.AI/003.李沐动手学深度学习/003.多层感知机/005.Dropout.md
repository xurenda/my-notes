# 丢弃法（Dropout）

## 动机

一个好的模型需要对输入数据的扰动鲁棒

- 使用有噪音的数据等价于 Tikhonov 正则
- 丢弃法：在层之间加入噪音

## 无偏差的加入噪音

对 $x$ 加入噪音得到 $x'$，我们希望：

$$
\begin{align}
E[x_i'] &= p \cdot 0 + (1-p)\frac{x_i}{1-p} \\
&=x_i
\end{align}
$$

丢弃法对每个元素进行如下扰动：（加入噪音不要改变期望）

$$
x_i'=\begin{cases}
0, & with\;probablity\;p \\
\frac{x_i}{1-p}, & otherwise
\end{cases}
$$

## 使用丢弃法

通常将丢弃法作用在隐藏全连接层的输出上

$$
\begin{align}
\mathbf{h}&=\sigma(\mathbf{W_1x+b_1}) \\
\mathbf{h'}&=dropout(\mathbf{h}) \\
\mathbf{o}&=\mathbf{W_2h'+b_2} \\
\mathbf{y}&=softmax(\mathbf{o})
\end{align}
$$

## 推理中的丢弃法

- 正则项只在训练中使用：他们影响模型参数的更新
- 丢弃法和正则的效果是一样的，可以看作是一种正则
- 在推理过程中，丢弃法直接返回输入（不做丢弃）：$\mathbf{h}=dropout(\mathbf{h})$
- 这样也能保证确定性的输出

## 总结

- 丢弃法将一些输出项随机置 0 来控制模型复杂度
- 常作用在多层感知机的隐藏层输出上
- 丢弃概率是控制模型复杂度的超参数

# dropout 代码实现

实现 `dropout_layer` 函数，该函数以 `dropout` 的概率丢弃张量输入 `X` 中的元素

```python
import torch
from torch import nn
from d2l import torch as d2l


def dropout_layer(X, dropout):
    assert 0 <= dropout <= 1
    # 在本情况中，所有元素都被丢弃
    if dropout == 1:
        return torch.zeros_like(X)
    # 在本情况中，所有元素都被保留
    if dropout == 0:
        return X
    mask = (torch.rand(X.shape) > dropout).float()
    return mask * X / (1.0 - dropout)

X= torch.arange(16, dtype = torch.float32).reshape((2, 8))
print(X)
print(dropout_layer(X, 0.))
print(dropout_layer(X, 0.5))
print(dropout_layer(X, 1.))
```

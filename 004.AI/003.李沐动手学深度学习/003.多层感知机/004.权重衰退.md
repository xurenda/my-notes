权重衰退（Weight Decay）是最常见的处理过拟合的方法

# 使用均方范数作为硬性限制

通过限制参数值的选择范围来控制模型容量

![[Pasted image 20250913202558.png]]

参数值的选择范围小就无法拟合成这种变化幅度非常大的曲线

$$
\min l(\mathbf{w},b)\; subject\;to\;\;||\mathbf{w}||^2 \leq \theta
$$

- 通常不限制偏移 b（限不限制都差不多）
- 小的 $\theta$ 意味着更强的正则项

# 使用均方范数作为柔性限制

对每个 $\theta$ ，都可以找到 $\lambda$ 使得之前的目标函数等价于下面：

$$
\min l(\mathbf{w},b)+\frac{\lambda}{2}||\mathbf{w}||^2
$$

可以通过拉格朗日乘子来证明

超参数 $\lambda$ 控制了正则项的重要程度：

- $\lambda=0$：无作用
- $\lambda \to \infty, \mathbf{w^*} \to 0$

对最优解的影响：

![[Pasted image 20250913193156.png|500]]

# 参数更新法则

计算梯度：

$$
\frac{\partial}{\partial\mathbf{w}}(l(\mathbf{w},b)+\frac{\lambda}{2}||\mathbf{w}||^2) = \frac{\partial l(\mathbf{w},b)}{\partial\mathbf{w}}+\lambda\mathbf{w}
$$

时间 t 更新参数：

$$
\begin{align}
\mathbf{w_{t+1}} &=\mathbf{w_{t}}-\eta\frac{\partial}{\partial\mathbf{w}} \\
&=(1-\eta\lambda)\mathbf{w_{t}}-\eta\frac{\partial l(\mathbf{w_t},b_t)}{\partial\mathbf{w_t}}
\end{align}
$$

与不加惩罚项，多了个 $-\eta\lambda$，通常 $\eta\lambda<1$，所以就是把当前权重做了放小，在深度学习中通常叫做权重衰退

# 总结

- 权重衰退通过 L2 正则项使得模型参数不会过大，从而控制模型复杂度
- 正则项权重是控制模型复杂度的超参数

# 简洁实现

```python
import torch
from torch import nn
from d2l import torch as d2l
```

生成一些训练数据：

$$
y = 0.05 + \sum_{i = 1}^d 0.01 x_i + \epsilon \text{ where }
\epsilon \sim \mathcal{N}(0, 0.01^2)
$$

```python
n_train, n_test, num_inputs, batch_size = 20, 100, 200, 5
true_w, true_b = torch.ones((num_inputs, 1)) * 0.01, 0.05
train_data = d2l.synthetic_data(true_w, true_b, n_train)
train_iter = d2l.load_array(train_data, batch_size)
test_data = d2l.synthetic_data(true_w, true_b, n_test)
test_iter = d2l.load_array(test_data, batch_size, is_train=False)
```

简洁实现：

```python
def train_concise(wd):
	net = nn.Sequential(nn.Linear(num_inputs, 1))
	for param in net.parameters():
	    param.data.normal_()
	loss = nn.MSELoss(reduction='none')
	num_epochs, lr = 100, 0.003
	# 偏置参数没有衰减
	trainer = torch.optim.SGD([
	    {"params":net[0].weight,'weight_decay': wd},
	    {"params":net[0].bias}], lr=lr)
	animator = d2l.Animator(xlabel='epochs', ylabel='loss', yscale='log',
	                        xlim=[5, num_epochs], legend=['train', 'test'])
	for epoch in range(num_epochs):
	    for X, y in train_iter:
	        trainer.zero_grad()
	        l = loss(net(X), y)
	        l.mean().backward()
	        trainer.step()
	    if (epoch + 1) % 5 == 0:
	        animator.add(epoch + 1,
	                     (d2l.evaluate_loss(net, train_iter, loss),
	                      d2l.evaluate_loss(net, test_iter, loss)))
	print('w 的 L2 范数：', net[0].weight.norm().item())
```

# 函数极限的概念

## 自变量趋向于无穷大

**定义**：

- 函数趋向于正无穷：$\lim_{x\to+\infty}f(x)=A$：$\forall\boldsymbol{\varepsilon}>\boldsymbol{0},\exists\boldsymbol{X}>\boldsymbol{0}$，当 $x>\boldsymbol{X}$ 时，恒有 $|f(x)-A|<\varepsilon$
- 函数趋向于负无穷：$\lim_{x\to-\infty}f(x)=A$：$\forall\boldsymbol{\varepsilon}>\boldsymbol{0},\exists\boldsymbol{X}>\boldsymbol{0}$，当 $x<\boldsymbol{-X}$ 时，恒有 $|f(x)-A|<\varepsilon$
- 函数趋向于无穷：$\lim_{x \to \infty}f(x) = A$：$\forall\boldsymbol{\varepsilon}>0,\exists X>0,\lvert x \rvert >X$ 时有 $\lvert f(x) - A\rvert < \varepsilon$

**解释**：

- 函数趋向于无穷意思是：x 的绝对值趋向于无穷

**函数极限和数列极限的关系**：

- 由**函数极限可以推导出数列极限**的值，数列极限不能反过来证明函数极限的值
- 数列极限就是函数极限的特殊值：函数极限从 0 开始取正数，然后趋向于无穷（趋向于正无穷）

**定理**：

$$
\lim_{x \to \infty}f (x)=A \Leftrightarrow \begin{cases} \lim\limits_{x \to +\infty}f (x)=A\\ \lim\limits_{x \to -\infty}f (x)=A\\ \end{cases}
$$

**解释**：

- 只有 $f(x)$ 的正负无穷相等时，才可以证明 $\lim_{x \to \infty}f (x)$ 存在
- 注意点：
	- 在数列极限中，x 趋向于无穷 = x 趋向于正无穷
	- 在函数极限中，x 趋向于无穷 = x 的绝对值趋向于无穷

## 自变量趋向于有限值

**定义**：${\lim_{x\to x_0}f(x)=A}$：$\forall\varepsilon>0,\exists\delta>0$，当 $0<|x-x_0|<\delta$ 时，恒有 $|f(x)-A|<\varepsilon$

**解释**：

- $x$ 趋向于靠近 $x_0$ 附近的邻域：$A-\varepsilon<f (x)<A+\varepsilon$
- 注意：$x$ 趋向于 0 与 $f(x)$ 趋向于 0
	- $x\to x_0$，但 $x\neq x_0$
	- 但是对 $f(x)$ 而言，它有时是 $f(x)\rightarrow A$，有时是 $f(x)=A$，得看这一点的性质
	- 比如 $\lim_{x\to0}\frac{\sin x}x=1$，$x$ 不能等于 0，但 $f(x)$ 趋向 0 等于 1

**结论**：

- 函数在 $x_0$ 点的极限，和函数的 $f(x_0)$ 无关
- $\lim_{x->x_0}f(x)$ 与 $f(x_0)$ 无关，只和去心领域的定义有关

# 单侧极限

 **定义**：
 
1. 左极限：$\lim_{x \to x_{0}^{-}}f(x) = A \Leftrightarrow \forall \varepsilon >0,\exists \delta>0,x_{0}-\delta <x<x_{0}$ 时有 $\lvert f(x) - A\rvert < \varepsilon$
2. 右极限：$\lim_{x \to x_{0}^{+}}f(x) = A \Leftrightarrow \forall \varepsilon >0,\exists \delta>0,x_{0}<x<x_{0}+\delta$ 时有 $\lvert f(x) - A\rvert < \varepsilon$

**定理**：$\lim_{x\to x_0}f(x)=A\Leftrightarrow\lim_{x\to x_0^-}f(x)=\lim_{x\to x_0^+}f(x)=A$

**解释**：极限存在：左右极限都存在**并相等**

**常见需要区分左右极限的三种情况**：

1. 分段函数在**分界点**处的极限（在分界点的左右两侧，函数表达式不同）
2. $e^{\infty}$ 型极限（$\lim_{x\to0}e^{\frac1x},\lim_{x\to\infty}e^x,\lim_{x\to\infty}e^{-x}$）
	- e 的指数趋向于无穷
	- 出现 e 指数是无穷时，一定要注意是正无穷还是负无穷，并需要分开讨论左右极限
		- 因为 $e^{+\infty}=+\infty$；$e^{-\infty}=0$
	- 举例：
		- $\lim_{x\to\infty}e^x$：$\lim_{x\to+\infty}e^x=+\infty$；$\lim_{x\to-\infty}e^x=0$
		- $\lim_{x\to0}e^{\frac1x}$：$\lim_{x\to 0^+}e^{\frac 1 x}=+\infty$；$\lim_{x\to0^{-}}e^{\frac{1}{x}}=0$
3. $\arctan(\infty)$ 型极限
	- $\lim_{x\to0}\arctan\frac{1}{x}$
	- 例：已知 $\lim_{x\to0}\left[a\arctan\frac1x+\left(1+|x|\right)^{\frac1x}\right]$ 存在，求 $a$ 的值？
		- 因为出现了 $arctan \infty$，而且还出现了 $x$ 的绝对值（分段函数），所以直接分左右讨论
		- $\lim_{k\to0^+}\left[\arctan\frac1k+(1+x)^{\frac1k}\right]=\frac\pi2a+e$
		- $\lim_{k\to0^-}\left[\arctan\frac1k+(1-x)^{\frac kk}\right]=-\frac\pi2a+e^{-1}$
		- 所以 $\frac\pi2a+e = -\frac\pi2a+e^{-1}$，可以解出 $a$ 的值

**补充：$\arctan$ 的定义**

$\tan(\arctan x)= x$

# 函数极限的性质

## 有界性

**数列**：

- 如果数列 $\left\{x_n\right\}$ 收敛，那么数列 $\left\{x_n\right\}$ 一定有界
- 收敛数列必有界
- **有界数列未必收敛**
	- 例子：$(-1)^n$

**函数**：

- 若 $\lim_{x\to x_0}f(x)$ 存在，则 $f(x)$ 在 $x_0$ 某去心邻域有界（即局部有界）
- **极限是函数的一个局部性态**
- 但局部有界时，不一定有极限；
	- 例子： $\lim_{x\to0}\sin\frac1x$，其在趋向于 0 时一直局部震荡

## 保号性

 **数列**：
 
设 $\lim_{n\to\infty}x_n=A$

- 如果 $A>0$（或 $A<0$），则存在 $N>0$，当 $n>N$ 时，$x_n>0$（或 $x_n<0$）
	- 即：当 N 大到一定程度时，一定会有数列的项和 A 保持一样的正负号
- 如果存在 $N>0$，当 $n>N$ 时，$x_n\geq0$（或 $x_n\leq0$）则 $A\geq0$（或 $A\leq0$）
	- 注意这里是大于等于符号：$\mathrm{X_n\geqslant0\longrightarrow A\geqslant0}$
	- 但只是大于时，不能推出 A 也是大于 0
 
**函数**：

设 $\lim_{x\to x_0}f(x)=A$

- 如果 $A>0$（或 $A<0$），则存在 $\delta>0$，当 $x\in U(x_0,\delta)$ 时，$f(x)>0$（或 $f(x)<0$） 
- 如果存在 $\delta>\mathbf{0}$，当 $x\in U(x_0,\delta)$ 时，$f(x)\geq0$（或 $f(x)\leq0$），那么 $A\geq0$（或 $A\leq0$）

# 极限与无穷小的关系

**关系**：$\lim f(x)=A\Leftrightarrow f(x)=A+\alpha(x)$，其中 $\lim\alpha(x)=0$

即：$f(x)$ 以 A 为极限的充要条件是 $f(x)$ 等于 A 加上无穷小
